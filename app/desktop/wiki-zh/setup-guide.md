# 设置指南

这份指南帮助你从接线、连接飞控开始，完成接收机、图传、电机和模式设置。命令、协议名称和引脚标记保留英文，方便与飞控说明书和地面站核对。不同固件版本的界面可能不同，请以实际板型和版本为准。

## 先确认硬件和接线

接线前先阅读飞控和电调说明书，确认供电电压、焊盘功能和接口方向。接收机、图传、GPS 和其他传感器分别使用哪个 UART、I2C 或 SPI，要提前安排。不要把供电焊盘当成信号焊盘。

未安装的飞控不要摔落或受到冲击，板载加速度计可能因此损坏。

## 连接飞控

使用支持数据传输的 USB 线连接飞控。在设备列表选择对应的 COM 端口，再点击“连接”。普通连接用于读取和修改设置；DFU 用于烧录固件，两者不是同一种设备接口。

如果没有端口，先更换数据线、USB 接口并关闭占用串口的软件。DFU 已经出现但不能烧录时，检查对应设备是否使用 WinUSB 驱动。不要把其他 USB 设备的驱动改掉。

连接成功后，轻轻转动飞控，检查设置页中的三维模型是否同步运动。需要时进行加速度计校准；磁力计校准只适用于实际装有磁力计的设备。

## 修改前保存配置

在命令行输入 `diff all` 或 `dump`，把输出保存到文件。升级固件可能重置设置。地面站允许不备份直接刷写，是否保存原配置由你决定。

## 接收机设置

先确认接收机接到哪个 UART。接在 RX1/TX1 上通常是 UART1，接在 RX2/TX2 上通常是 UART2，具体以飞控说明书为准。

在“端口”页为接收机所在 UART 打开“串行接收机 / Serial RX”。不要同时把同一 UART 配置成 MSP 和 Serial RX。

在“接收机”页选择“串行接收机（UART）”，再选择实际使用的协议：

| 接收机系统 | 常用协议 |
| --- | --- |
| ELRS、Crossfire、Tracer | CRSF |
| FrSky | SBUS 或 FPort，以接收机输出设置为准 |
| FlySky | IBUS |
| Spektrum | 对应的 Spektrum 或 SRXL2 协议 |

板载 SPI 接收机不需要为接收机设置 UART，请选择 SPI 接收机模式及对应的驱动。云编译可以包含多个接收机协议，但运行时仍要选择当前实际使用的协议。

推动遥控器摇杆，确认各通道的数值和方向正确。通道顺序不对时调整“通道映射 / Channel Map”。

## 图传和 OSD

### 模拟图传

基本视频通常不依赖串口配置。通过遥控器调整图传频道和功率时，需要连接 SmartAudio 或 Tramp 控制线，并在对应 UART 的外设列表中选择协议，再在“图传”页加载与设备相符的频率表。

频率表的功率数值、功率标签和实际发射功率不一定相同，不能直接套用别人的表。

### 数字图传

在图传对应 UART 选择 `VTX (MSP + DisplayPort)`，并按设备说明配置。旧版固件的菜单和配置方法可能不同。需要时使用适用于当前固件版本的图传预设。

固件同时包含 Analog 和 Digital OSD，只表示两类驱动都被编译进去；实际输出方式仍需按硬件设置。

## 电机设置

在“电机”页选择电调支持的输出协议。常见数字电调使用 DShot300 或 DShot600。BMI270 等较低采样率陀螺仪和较慢主控通常优先考虑 DShot300；具体还要结合循环频率和电调能力。

**测试电机前拆下全部螺旋桨。**接通电池，确认安全选项后缓慢提高电机滑块，逐个检查电机编号、转向和响应。如果编号不对，进行电机输出重排；转向不对则按电调支持的方法修改。

## 模式设置

“模式”页通过 AUX 通道和范围滑块分配开关。`ARM` 是解锁开关，建议使用独立且不容易误触的开关。

1. 在 ARM 项点击“添加范围”。
2. 选择对应 AUX 通道，或使用 AUTO 后拨动目标开关。
3. 调整滑块，使开关在解锁位置时落入范围。
4. 检查另一个开关位置处于范围外，再点击“保存”。

常用模式：`BEEPER` 为蜂鸣器，`ANGLE` 为自稳，`HORIZON` 为半自稳，`PREARM` 为预解锁。没有激活自稳模式时，通常是 Acro（手动角速度）模式。

## 失控保护、OSD 和起飞前检查

按机型设置失控保护，并在拆桨状态下验证遥控信号丢失后的行为。需要 GPS 救援时，先完成 GPS、救援参数和实际环境测试；勾选功能不能代替正确配置。

在 OSD 页放置所需信息，检查电压、警告、RSSI 或链路质量等是否实际显示。起飞前还要核对电池、电机转向、桨叶方向、接收机通道、解锁开关、失控保护和紧固件。
