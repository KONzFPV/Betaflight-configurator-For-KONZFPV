空致 KONz 2026.6.2 免安装预览版 5（Windows x64）

使用方法
1. 完整解压 release/KONz-2026.6.2-Preview5-Windows-x64.zip 到一个文件夹。
2. 运行解压目录中的“空致 KONz.exe”。不要只复制 EXE。
3. 本机已解压好，可直接运行 release/win-unpacked/空致 KONz.exe。

已包含
- 双 OSD 默认同时选择；接收机、电机协议可多选，电机默认 DSHOT。
- 默认 LED64、磁力计、舵机；默认专家模式。
- 陀螺仪、气压计、黑匣子存储芯片驱动选项，保留原始自定义宏框。
- 三条 CF 线路，打开烧写工具自动测速选择，可手动切换及重新测速。
- 获取编译好的固件按钮，烧录不强制弹出备份保存。
- 空致 KONz 品牌、中文首页、本地 Wiki 和黑匣子浏览器。
- 简体中文和 English 两种语言。
- BF地面站首页、B站 / 抖音：FPVFIX、维修介绍、交流群 1075517252 与扫码入口。
- 视频教程：支持刷新 FPVFIX B站投稿列表，遭遇 B站风控时显示缓存及主页入口。
- 支持快照：加载官方 Support ID 或本地 CLI / dump / diff 文本文件，按分类只读查看配置与完整记录。

预览版范围
Wiki 包含 317 篇官方正文及离线中文稿，保留代码、参数、图片和英文原文；包含机器辅助翻译，技术细节需结合官方原文核对。
黑匣子补齐常用曲线、图例、图表设置和高级菜单中文；调试字段代码和用户命名保留原样。
传感器选项只加入驱动，总线、片选、中断与方向仍要匹配主板 target。
本次没有改写 APM32/STM32 烧录协议，也没有刷写实体飞控。

支持快照
查看快照不会向飞控发送命令或修改配置。
官方 Support ID 与第三方镜像自建的快照 ID 不一定互通；无法加载时可分享本地 CLI 文本。
提交快照仍在连接飞控后的命令行页面操作，软件会先让你确认提交支持数据。

运行环境
软件自带 Electron、Python 网络组件和所需 DLL，不需另外安装 Node、Python、.NET 或 WebView2。
DFU 仍需正确的 WinUSB 设备驱动。
本地设置、已下载固件和本地日志可离线使用；官方云编译和在线预设需要联网。
线路只显示编号和 HTTPS 往返延迟，客户无需配置 CF。
网络可达性随运营商和 CF 状态变化，不能保证所有地区始终可用。
