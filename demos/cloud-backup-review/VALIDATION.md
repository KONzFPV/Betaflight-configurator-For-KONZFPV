# 本地验证记录

日期：2026-11-01，北京时间。
环境：Windows，使用本机 Microsoft Edge 的独立无头测试实例；通过本地 HTTP 服务访问。测试数据与用户日常浏览器隔离。

已完成：

- 首次加载自动建立四条虚构示例，控制台无未处理 JavaScript 错误。
- 一键填入演示材料、确认说明、提交后进入待审核队列和投稿进度。
- 管理员查看材料，通过后先模拟发布再进入下载列表。
- 刷新后投稿和审核状态保留。
- 拒绝原因不允许全为空格；填写后状态和原因保存。
- 已发布记录下架后立即从本地下载列表移除，投稿进度显示下架原因。
- 下载确认和取消在前十秒禁用；Escape 在倒计时中不能跳过提示。
- 下载结果为明确标注“非固件”的 TXT，实际文件名及内容已经检查。
- 夜间模式、浅紫背景在刷新后保留。
- 错误 Intel HEX 校验和被拦截并提示。
- 用仅供测试、全部为 0xFF 的 256 KiB 连续数据生成内存 HEX，验证格式检查、所填容量匹配及文件 SHA-256；没有把这份测试 HEX 写入仓库或作为下载材料。
- 本地选图成功解码、缩图并转为 JPEG 数据，上传选择实际 HEX 后会清除一键填入的参考照片，要求重新选择材料。
- 1440 × 1050 桌面界面及 390 × 844 窄屏截图已查看；窄屏页面无整体横向溢出。
- 审核详情内容独立滚动，操作按钮固定在弹窗底部。

未验证／尚未实现：真实 GitHub 写入、OAuth、Cloudflare Worker、多人同步、服务器限频和完整固件兼容性验证。该 Demo 不能作为正式审核后台直接上线。
