# KONz 云备份投稿与审核 Demo

这是独立的 HTML/CSS/JavaScript 交互预览，不接入地面站，不需要安装依赖，不打包。

## 打开

在本目录执行：

```sh
node serve.mjs
```

浏览器访问 http://127.0.0.1:8879/#submit 。如需其他端口，用环境变量 PORT 指定。
请通过本地服务器访问，避免 file:// 的模块、存储和安全上下文差异。
也可以将本目录作为静态网站运行；本次仅推送源码，不部署网站。

## 验证路径

1. 在“飞控备份投稿”点击“一键填入演示材料”。
2. 勾选两项说明并提交，进入“投稿进度”。
3. 打开“云端审核”，查看对应投稿、放大两张照片。
4. 通过并确认，记录进入下载列表；拒绝则必须填写原因，投稿进度同步显示。
5. 在审核筛选选择“已发布”，打开记录并填写理由下架，下载列表随即移除。
6. 刷新浏览器，记录与主题继续保留。可以用左下角“重置演示数据”恢复初始状态。
7. 下载有 10 秒强制阅读提醒与勾选确认，只生成 TXT 说明，绝不生成演示 HEX。

## 数据与限制

- 本地 IndexedDB 保存选择的 HEX 内容、照片和审核状态；不会发送到 GitHub、Cloudflare 或任何外部服务。
- 五种 Material 背景（蓝、绿、紫、桃、沙）加 BF 默认背景，夜间模式独立切换，偏好保存至本地。
- 不同端口/主机属于不同站点存储，不共享数据；这不是多电脑同步的后台。
- 预置品牌/型号为虚构，配图是用户授权提供的拍摄参考，不是示例板型的硬件证据。
- “一键填入”只填演示占位，没有真实固件或伪造校验值。
- 支持实际选择 HEX 与两张 JPG/PNG/WebP 照片用于本地验证。HEX 限 12 MiB，解码数据限 4 MiB；照片单张 8 MiB，浏览器缩图后保存。
- HEX 检查长度、记录校验和、EOF、地址边界/连续性、重叠地址和所填容量；不能据此证明来自实机或适配某块飞控。
- 正式后台仍需服务端重新验证、GitHub 身份认证、限频配额、幂等发布等。Demo 不提供真实登录，不能拿它直接充当审核服务。
- 浏览器清理存储会删除演示材料，电脑上的原始文件不受影响。
- 请在一个标签页内验证流程；并发多标签页编辑不是本 Demo 的验证范围。
